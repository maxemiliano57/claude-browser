# Self-review patterns
The Copilot Agent AI didn’t really tell me about any errors, but it did suggest alot of edge cases and gave suggestions on how to make the feature better. It also made suggestions to make it more accessible. When there were certain things I needed a bit more explanation for, it gave me a good breakdown of the term and what exactly it does, so it was easier to understand. First it started with the very definition of the term and then started talking about how this term applies to my feature and what role it has to making my feature working. It helped me to better understand how the feature works.

# Browser tool vs. CLI comparison
I feel like the CLI tools are better and easier to work with compared to the browser tools. I feel like they are much easier to find and they open a window right next to the interface you are working with. It really does feel like a close, personal assistant. I did have some issues with the browser tools though. The Copilot Agent AI was easy to use, but I had a hard time finding it. You actively have to search with it. I read on the assignment tutorial that you could find it within VS Code. I had to look at the interface several times before I found the small button for it. The real issue was Claude on the web. The interface was confusing to interact with and after a certain point in my prompts, it started giving me error_log messages. I either had to start again or try to rephrase my prompts to something else. It took me an hour of playing around with it until I finally gave up and just used Copilot Agent AI instead. The Claude on the web interface has more features on its display so it was more confusing compared to the very simplistic and general interface on the CLI.

# When would you use micro-iteration + self-review?
I think using both micro-iteration and self-review make sense for certain tasks where you want to be really careful, like when you have to build something step-by-step or when you’re not sure what the final product should look like. I think it is perfect for when you need to catch mistakes early on and making sure each part works before moving on. I would probably skip it for tasks that are very simple or when I’m just making some quick changes, but for features that are much bigger or anything that needs to be reliable, it’s definitely helpful.
